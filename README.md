# AUREN — Premium D2C Lifestyle Storefront

A self-contained, responsive static website concept for the fictional brand AUREN.

## Run locally

Open `index.html` directly, or serve the folder with any static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Included

- Home, Shop, Collections, Product, Journal, Article, About, Contact, FAQ, Bag, Privacy and Terms pages.
- LocalStorage-powered bag/cart interactions.
- Product search overlay and shop filtering.
- Responsive navigation and mobile menu.
- Product gallery zoom modal.
- FAQ accordions.
- Semantic page structure, metadata, breadcrumbs, descriptive alt text, focus states and reduced-motion support.
- Locally generated editorial SVG art direction to keep the concept self-contained/offline. Replace these with commissioned photography for a commercial launch while retaining the same cropping and tonal direction.

## Academic / presentation note
The storefront copy is intentionally believable but does not fabricate certifications, awards, statistics, testimonials or manufacturing claims.
